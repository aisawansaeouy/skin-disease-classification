# skin-disease-classification
Skin Disease Classification using Gradient Boosting vs Random Forest Machine Learning Project  This project compares the performance of Gradient Boosting and Random Forest models for classifying skin diseases from medical images.

## Dataset
HAM10000 dataset (7 classes of skin lesion images)

## Methods
- Data preprocessing
- Train/test split
- SMOTE for data balancing
- Model training:
  - Gradient Boosting
  - Random Forest

## Evaluation
Models were evaluated using:
- Accuracy
- F1-score
- Classification Report

## Result
Both models achieved similar performance, but Random Forest performed slightly better.

## Tools & Libraries
Python, NumPy, Pandas, Scikit-learn, Matplotlib
